A program that writes one original one-line autocorrect fail to
`/output/entry.txt`: a hiring follow-up email where autocorrect swaps
one word for a far more embarrassing one, and the sender has to correct
it in the same breath. The line is 157 characters, inside the 1–199
gate, and reads as a real slip rather than a written joke.

## Run

Requires Node 22. No dependencies, no network.

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` with no trailing newline.
